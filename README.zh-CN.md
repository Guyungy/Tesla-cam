# Tesla Cinema — 特斯拉行车记录仪查看器

**English** · [简体中文](./README.zh-CN.md)

一款现代化的桌面端 Tesla DashCam 查看器：多路摄像头同步播放、从 SEI 元数据实时解析行车遥测、GPS 轨迹回放，以及 H.264 视频导出。

## 功能特性

### 多路摄像头同步播放

所有摄像头逐帧精确同步，并提供多种布局：

| 布局         | 说明                                 |
| ------------ | ------------------------------------ |
| **六宫格**   | 6 路摄像头 3×2 排列（含 B 柱摄像头） |
| **四宫格**   | 前 / 后 / 左 / 右 2×2 排列           |
| **经典四分** | 前摄在上（占 60%），其余三路在下     |
| **单画面**   | 任意单路全屏 —— 双击即可切换         |

每个画面都带有摄像头标签（前 / 后 / 左 / 右 / 左 B 柱 / 右 B 柱），便于快速辨认。

### B 柱摄像头支持

完整支持特斯拉车内 B 柱摄像头（`left_pillar` / `right_pillar`）。自动识别 —— 只有存在 B 柱文件时才会出现六宫格布局。

### 实时行车仪表盘

自动解析特斯拉行车记录仪 H.264 码流中内嵌的 SEI 元数据，并实时叠加显示：

- **车速** —— 大号仪表，按绿 / 黄 / 红分色
- **挡位** —— P / R / N / D 高亮
- **方向盘转角** —— SVG 弧形指示器 + 角度读数
- **踏板** —— 油门（绿条）与刹车（红条）
- **辅助驾驶状态** —— OFF / AP / FSD / TACC 徽标
- **GPS 坐标** —— 纬度 / 经度

> **注意：** 车辆元数据仅在 **HW3+** 硬件、且特斯拉固件 **2025.44.25** 及以上版本录制的视频中存在。驻车状态下也可能没有 SEI 数据。

### 进度条车速曲线

鼠标悬停时间轴时，进度条背景会绘制车速随时间的曲线。急加速、急刹、匀速巡航一眼可见。

### 智能筛选与按日期分组

- 按类型筛选：**全部 / 近期 / 哨兵 / 已保存** —— 附实时片段计数徽标
- 按日期、地点或事件原因搜索
- 片段按日期分组：**今天 / 昨天 / 2025-04-03...**
- **真实视频缩略图** —— 滚动时惰性从前摄抽取封面帧
- 片段卡片上直接显示事件原因（如"检测到物体"）
- 侧边栏宽度可拖拽调整，并在会话间记忆

### GPS 轨迹面板

视频上叠加一个紧凑的实时轨迹面板：显示该片段完整的行驶路径，以及随拖动而移动的播放头。完全由 SEI GPS 采样点渲染为纯 SVG —— 全离线，无需地图瓦片。一键折叠。

### 事件智能分析

- **急刹标记** —— 结合刹车输入的急剧降速会从 SEI 遥测中识别出来，并以琥珀色标记在时间轴上，碰撞与险情一眼可见
- **自动跳转到事件点** —— 事件片段直接从事发前开始播放（AEB 提前 3 秒，哨兵 / 已保存提前 5 秒），而不是从头播
- **哨兵触发摄像头聚焦** —— 哨兵片段直接打开触发告警的那一路摄像头（读取 `event.json`），无法判断时回退到网格视图
- 以上三项均可在设置中开关

### 播放与导航

- 当前片段结束后**自动播放下一个**（可在设置中开关）
- **↑ / ↓** —— 不碰鼠标即可切换上 / 下一个片段
- **Delete** —— 分诊流程：确认 → 移入回收站 → 自动跳到下一个
- **空格** 播放 / 暂停 · **← / →** ±5 秒 · **Shift+← / →** ±1 秒
- **， / 。**（即 `,` / `.`）—— 逐帧步进（会暂停播放，便于精确查看）
- **M** 静音 · **F** 全屏 · **P** 画中画 · **I / O** 设置导出入 / 出点
- 记住你上次使用的布局，并在打开新片段时恢复

### H.264 视频导出

由 FFmpeg 驱动的当前视图（任意布局）导出为 H.264 MP4：

- **快速通道**：直接以源文件走 `filter_complex` 合成（多路网格 + 叠加层）—— 无需 canvas 逐帧传输
- **硬件编码**：自动检测 NVENC / QuickSync / AMF（可在设置中开关），GPU 编码失败时自动回退到 libx264
- **降级方案**：当磁盘路径不可用时走 canvas RGBA 流
- 设置 **IN / OUT** 点精确裁剪片段（时间轴上显示为蓝色区间）
- 叠加内容：**实时走动的时钟**、地点，以及按时间窗从真实 SEI 遥测采样的行车数据（车速 / 挡位 / 辅助驾驶）—— 摄像头标签本地化
- 通过 drawtext 文本文件实现 Unicode 安全的叠加文字（中日韩字符、撇号、`%`）
- 合成导出最长支持 **10 分钟**；旧的 canvas 通道上限 60 秒
- 导出弹窗显示进度与预计剩余时间
- 一键导出截图（JPEG）

### 行车数据 CSV 导出

将完整行车遥测导出为 CSV，便于进一步分析：

```
offset_s, speed_kph, gear, steering_deg, brake_pct, throttle_pct, ap_status, latitude, longitude
```

### 地图集成

- **区域自动识别**：中国坐标 → 高德地图，其余 → Google Maps
- 两个地图链接同时显示在顶栏
- 点击即可打开事件发生的确切位置

### 中英双语界面

完整支持中文与英文。语言根据浏览器设置自动识别，也可在设置中切换（标题栏齿轮图标）。时间戳、标签及所有界面文案均跟随所选语言。

## 兼容性

| 项目         | 要求                                                                     |
| ------------ | ------------------------------------------------------------------------ |
| 操作系统     | Windows 10+ · macOS 11+ · Linux (x64)                                    |
| 特斯拉素材   | 标准 `TeslaCam` 目录结构（`RecentClips` / `SentryClips` / `SavedClips`） |

## 开发

### 环境要求

- Node.js >= 20.12
- npm

### 安装

```bash
npm install
```

### 开发模式

```bash
npm run dev
```

### 打包

```bash
# Windows
npm run build:win

# macOS
npm run build:mac
```

产物输出到 `release/` 目录。

### 技术栈

- **Electron 40** —— 桌面外壳（启用 `contextIsolation`，禁用 `nodeIntegration`）
- **React 19** + **TypeScript 5.8**
- **Tailwind CSS 4** —— 样式
- **Vite 5** —— 构建工具
- **FFmpeg**（经 ffmpeg-static 内置）—— filter_complex 合成 + H.264 编码
- **自研 SEI 解析器** —— 流式 MP4 NAL 扫描 + 特斯拉 protobuf（零依赖）
- **MP4 时长探测** —— 解析 moov/mvhd box（片段并行加载，无需逐个 `<video>` 试探）

### 可选的 Python 工具

`tesla_cinema/` 包与 `sei_extractor.py` 属于**可选的辅助工具**（SEI 实验 / 另一套 PySide6 查看器）。产品本体是 Electron：

```powershell
python -m pip install -e .
python -m tesla_cinema   # Qt 查看器（实验性）
```

## 测试

每次推送，CI 都会运行 lint、类型检查、生产构建以及 Playwright 测试套件（见 [`.github/workflows/ci.yml`](./.github/workflows/ci.yml)）。本地复现：

```bash
npm run lint                                  # eslint
npx tsc -b --noEmit                           # 渲染进程类型检查
npx tsc -p tsconfig.electron.json --noEmit    # 主进程类型检查
npx vite build                                # 生产构建
npx playwright test                           # 全量测试
```

大部分用例是单元级测试，始终会运行。依赖素材的用例（`realDrive.spec.ts`、`composeExport.spec.ts`）需要接入真实的特斯拉 U 盘，**未接入时会自动跳过**，因此 CI 始终保持绿色：

```bash
# Windows
TESLACAM_DIR='G:\TeslaCam' npx playwright test

# macOS / Linux
TESLACAM_DIR=/Volumes/TeslaCam npx playwright test
```

> 仓库中的 `_sample_TeslaCam/` 是用于界面测试的**重编码**小样本 —— 它的 SEI 里装的是 x264 编码器标识串，并非特斯拉遥测，因此针对该目录运行遥测提取用例时仍会跳过。

## 项目结构

```
electron/          Electron 主进程（窗口、IPC、导出、回收站）
src/
  app/             应用外壳、路由、首页与启动页
  components/      界面组件
    viewer/        播放器、布局、仪表盘、时间轴、GPS 轨迹
  i18n/            本地化（en、zh-CN）与语言上下文
  plugins/         播放扩展
  utils/           SEI 解析、片段生成、导出、MP4 探测
scripts/           开发 / QA 辅助脚本（SEI 覆盖率、同步校验、导出探测）
tests/             Playwright 用例 —— 单元测试 + 真实盘测试（自动跳过）
tesla_cinema/      可选的 Python / PySide6 实验代码
sei_explorer.html  独立的 SEI 检视页面
```

各分区大致按优先级排列。以下内容**不构成发布承诺**，它是一份持续演进的清单 —— 欢迎通过 [issue / PR](#参与贡献) 推动其中任何一项。

## 参与贡献

任何规模的贡献都欢迎 —— 缺陷报告、素材样本、翻译以及 Pull Request 一律不限。

1. **先提 issue。** 对于小修复之外的改动，请先开 issue 对齐方案，避免你白花时间。
2. **Fork、开分支、保持改动聚焦** —— 一个 PR 只解决一件事。
3. **遵循现有风格。** 仓库使用 Prettier 格式化、ESLint 校验，推送前请先运行：

   ```bash
   npm run format
   npm run lint
   npx tsc -b --noEmit && npx tsc -p tsconfig.electron.json --noEmit
   npx vite build
   npx playwright test
   ```

4. **说明你的测试情况。** 写清跑了哪些测试；涉及遥测的改动，请注明素材对应的固件版本与硬件型号。
5. **请勿提交个人素材或位置信息。** 在附上含 GPS 的片段前，请先打码或裁剪。

PR 需在 CI 全绿后方可合并。
