# Tesla Cam 启动指南

## 项目信息

- **名称**: Tesla Cinema - Tesla Dashcam Viewer
- **技术栈**: Vite + Electron + React + TypeScript + Tailwind CSS
- **端口**: 5174

## 快速启动

### Step 1: 安装依赖

```bash
npm install
```

### Step 2: 启动开发服务器

```bash
npm run dev
```

等待 Electron 应用窗口自动打开。

## 其他命令

- `npm run build` - 构建生产版本
- `npm run lint` - 代码检查
- `npm run format` - 代码格式化
